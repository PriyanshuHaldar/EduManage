# Student Management System

A comprehensive Student Management System project.

## Directory Structure

- **`frontend/`**: Frontend web application.
- **`backend/`**: Backend API and application logic.
- **`terraform/`**: Infrastructure as Code (IaC) provisioning templates.
- **`puppet/`**: Configuration management manifests and modules.
- **`jenkins/`**: Jenkins CI/CD pipeline definitions and configurations.
- **`nagios/`**: System and service monitoring configurations.
- **`.github/workflows/`**: GitHub Actions automated workflows.
